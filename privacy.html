プライバシーポリシー（ryo-youtube）

「ryo-youtube」は、運営者が自分の管理するYouTubeチャンネルに動画を投稿し、再生数や視聴維持率を確認するためだけに使う、社内用のツールです。一般の方に提供するサービスではありません。

1. 取得する情報

Googleアカウントでのログインを通じて、次の情報にアクセスします。

  • YouTubeへの動画のアップロード（youtube.upload）
  • 自分のチャンネルと動画の情報の読み取り（youtube.readonly）
  • 自分のチャンネルの分析データの読み取り（yt-analytics.readonly）

2. 使い方

取得した情報は、動画の投稿と、運営者自身の動画の成績の記録にだけ使います。第三者への提供、販売、広告への利用はしません。

3. 保存

ログインの情報（トークン）と分析の数字は、運営者のパソコンの中にだけ保存します。外部のサーバーには送りません。

4. 取り消し

アクセスの許可は、Googleアカウントの「サードパーティのアプリとサービス」（https://myaccount.google.com/connections）からいつでも取り消せます。

5. Googleのデータの扱い

本ツールによるGoogle APIから受け取った情報の利用と移転は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。また、YouTube API サービスの利用規約と、Googleのプライバシーポリシー（https://policies.google.com/privacy）に従います。
